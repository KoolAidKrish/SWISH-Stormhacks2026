# SWISH landing page

React + Vite site for SWISH. Three looks share the same content: `?v=1` Slate, `?v=2` Circuit, `?v=3` Neon
(or use the V1/V2/V3 switch in the nav).

```powershell
npm install
npm run dev      # http://localhost:5173
npm run build    # -> dist/
```

Deployed by Netlify from `netlify.toml` at the repo root (base `landing`, publish `dist`).
